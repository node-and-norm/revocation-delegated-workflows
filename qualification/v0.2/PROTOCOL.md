# v0.2 bounded protocol contract (before execution)

One root `rootR`, fixed grant epoch 7, parent principal `parentP`, registered child `childC`, one edge of protocol delegation. Gateway bootstraps parent grant `parent-0` with append scope `summary:task1` and a bounded right to delegate that scope to childC. The parent worker exercises that grant through its own bound IPC channel. Only the gateway issues child grant `child-1`, inheriting root/epoch, bound to childC, without further delegation rights. Parent sends the returned token to child on a separate pipe. Child prepares and requests its own effect through its own gateway channel. Tokens are deterministic fixture identifiers, not claimed cryptographic capabilities.

Gateway derives principal from its server-side channel map, not an actor claim. Claimed actor mismatch, foreign/unknown grant and scope expansion fail. Parent cannot issue a descendant after root withdrawal. A dedicated controller channel alone can request fixture root revocation. Workers never open a database; the gateway owns write/enforcement code, and a separate observer has a read-only SQLite connection. Same OS user and accessible filesystem mean this is assumed code-path mediation, NOT hostile process confinement.

Both arms enforce owner and scope equally at final effect. The diagnostic admission-only arm intentionally reuses a prior successful freshness admission; commit-fenced rechecks root active/epoch in the same `BEGIN IMMEDIATE` transaction as effect insertion. Revocation and grant issuance use the same SQLite transaction domain. One unique effect key and inert payload, `inert summary`, are fixed. No regrant, partial revoke, new scopes, grandchildren, remote action, models or actual user data.

Nine schedules per arm maximum: C0 live; C1 revoke before child commit; C2 pre-fence commit with delayed explicit application acknowledgement; C3 three stale attempts of the same key; C4 child effect scope expansion; C5 child claims parent identity; C6 child presents parent's grant (foreign owner); C7 parent requests expanded child delegation; C8 root revoke before parent requests child grant. C5 is not a nonexistent transport channel; an unregistered actor string cannot create a server channel. Unknown grant is additionally tested at unit/API level. Maximum two worker processes, one gateway and one read-only observer per sequential case, one logical effect, three attempts, one child grant. All IPC waits/process joins bounded at ten seconds. No sleep-based ordering, background work or unbounded scheduling. Fresh run directories preserve all failures.

Worker local intent and response records, gateway IPC receipt, gateway admission, protected DB commit and explicit application ack are separate records. Gateway sends its execution response only after transaction commit. The delayed ack control delays a separate application ack, not the already received gateway response. Commit order is inferred from same-transaction event/sink rows in observer snapshots. Parent-child delivery is worker/harness evidence, not independently measured by DB observer. Observer is independent of enforcement code but same-host and not tamper-proof. Missing/conflicting/malformed evidence yields nonpass.

Stop after finite qualification, separate AI-assisted review/corrections and package. No population estimates, universal safety claims or additional studies.
