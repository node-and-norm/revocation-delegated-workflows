# Shared revocation research records v0.1

Stage-one draft for review, 4 November 2026 UTC. AI-assisted vocabulary and evidence registry for the private study. This is not a formal ontology, runtime change, experiment or independent human validation.

## Read first

Request acceptance, fence installation, caller confirmation and effect are separate facts. The historical request-to-fence report records twelve passing deterministic cases. Temporal has setup evidence, four schema-only passes and a blocked bridge attempt, but no native Workflow/Activity result. Proposed six-cell expectations are not observations.

## Contents and source resolution

- [Glossary](glossary.json): fourteen definitions, required evidence and forbidden inferences.
- [Evidence registry](evidence_registry.json): ten selected claims with evidence status and limits.
- [Source manifest](source_manifest.json): resolve each source_key to a repository_path relative to the repository root, and, when present, archive_member within that ZIP. SHA-256 binds the resolved file/member bytes, not correctness or authenticity.
- [Reconciliation](sources/reconciliation.md): source-reviewed acceptance gaps; no execution authorization.
- [Later stages](LATER_STAGES.md): proposed stable identifiers and a graph usefulness gate, neither implemented nor evaluated.

Eight source records reuse byte-identical repository files or existing archive members. Reconciliation is retained byte-for-byte. The Temporal status is an explicitly identified derivative omitting private conversation identifiers and the quoted authorization exchange; its original and derivative hashes are recorded. No historical source, archive or research result was changed. References within source records retain their historical context and may name files within existing archives rather than clickable repository paths.

## Review and correction policy

This integration retains the reviewed local glossary and evidence-registry bytes. Its UNCONFIRMED_AT_OBSERVATION_END definition requires a PENDING caller at observation end, and its measured-case source locator names Interpretation limits. Source-review findings remain distinct from empirical results and independent human validation.

Keep proposed, reported historical result, source-review finding, partial/blocked and unresolved distinct. Absence of evidence is unresolved unless complete bounded evidence supports absence. A future correction must retain prior assertions and source versions with explicit replacement/supersession links. Source keys are lookup labels, not the study-wide stable IDs proposed for stage two.

Package and repository SHA256SUMS cover retained bytes, excluding their own checksum file. Validation in this integration checks source resolution, hashes, links and historical preservation. It does not reopen all raw SQLite records, replay checkers, revalidate a runtime or independently authenticate a source. This remains private research; no public release is authorized.
