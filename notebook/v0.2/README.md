# Portable research notebook v0.2

[Download the Obsidian-compatible notebook](Revocation_Research_Notebook_v0.2.zip), unzip it, and open the Revocation_Research_Notebook_v0.2 folder as a vault. Start with START_HERE.md. Ordinary Markdown readers also work.

The notebook contains twelve Markdown notes, an optional Canvas map, shared JSON/CSV records, the current workbook and canonical specification/qualification/pilot archives. Its workbook attachment is byte-identical to the [separate v0.2 workbook](../../docs/traceability/v0.2/Revocation_AI_Use_and_Research_Decision_Traceability_v0.2.xlsx).

The v0.1 notebook remains unchanged. This portable package does not update the existing Mac vault or establish live synchronization. Desktop Obsidian and Excel were not opened; the workbook was rendered and the package's local links, file copies and checksums were checked. QA.md describes those checks.

The record is private and was captured before verification of its later repository upload. It preserves the contribution HOLD and distinguishes the completed bounded integration pilot from any future research. Public release requires separate authorization and review.
